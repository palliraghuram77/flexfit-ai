# GEMINI.md

## Antigravity Context

This repository is intended to work well in Google Antigravity and other AI-first coding environments. The app is intentionally static so agents can inspect, edit, and verify it without installing dependencies.

## Preferred Workflow

1. Read `README.md` for the project goal.
2. Read `AGENTS.md` for shared coding rules.
3. Edit only the files needed for the requested change.
4. Verify the behavior in a browser after UI or JavaScript changes.
5. Explain changes in beginner-friendly language when the user is learning.

## Project Intent

The site should look like a real fitness SaaS landing page while also demonstrating practical front-end features for a resume:

- Dynamic workout plan generation
- Calorie and macro calculation
- Local progress tracking
- Responsive layout and mobile navigation
- GitHub Pages-ready static deployment

## Constraints

- Do not introduce a framework unless the user asks for it.
- Do not remove the portfolio and resume documentation from `README.md`.
- Do not replace the interactive features with static screenshots.
